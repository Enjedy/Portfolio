Singci — Signalement Urbain Citoyen

Singci est une solution complète permettant aux citoyens de signaler les infrastructures publiques endommagées. Développée en équipe, elle combine une application mobile intuitive et une plateforme web d'administration pour un suivi efficace des signalements.

  • Signalement géolocalisé des infrastructures endommagées
  • Interface mobile intuitive pour les citoyens
  • Dashboard web pour le suivi et la gestion des signalements
  • Développement en équipe avec méthodologie agile
App Mobile App Web API UI/UX

OVERDRIVE — Rallye 3D

OVERDRIVE est un jeu de course de rallye en 3D développé avec le moteur Unity pour l'ISPM. Créé en groupe, ce projet m'a permis d'explorer le game design, la physique 3D, et la programmation orientée objet en C# dans un contexte de développement de jeu complet.

  • Physique de conduite réaliste avec Unity
  • Design de pistes et environnements 3D
  • Système de scoring et gestion de parties
  • Travail en équipe avec répartition des rôles
Unity C# Game Design 3D
